A [make.fun](https://make.fun/bounty/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68) entry: one line describing a hilariously useless superpower — the gift of perfectly predicting which checkout queue will move slowest, but only after already joining it.

## The line

> I can perfectly predict which checkout queue will move slowest — but only after I have already joined it.

105 characters, one line, no more, no less.

## How it works

`main.py` (Python 3, no dependencies, no network, deterministic) writes
that single line to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
